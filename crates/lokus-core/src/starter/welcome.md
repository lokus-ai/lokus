Lokus keeps your notes as **plain Markdown files** in this folder. Nothing is locked in: open them with any other app, any time.

## Try these

- [ ] Type `**` and watch the closing pair appear
- [ ] Press `/` on an empty line for headings, lists, tables and more
- [ ] Type `[[` to link to another note, like [[Shortcuts]]
- [ ] Paste a screenshot straight into this note
- [ ] Open [[Roadmap]] to see notes shown as a board

> Click a line to see its Markdown. Click away and it reads like a page again.

## Pages

The icon and cover above live in the first lines of this file. Hover over the title to change them.

## Working with others

*Sync with a team* in the sidebar connects this folder to a workspace. Everyone edits the same notes live, and edits made offline are merged when you are back.

## The assistant

Add your own API key in Settings, then press the Assistant shortcut and ask about your notes. It can search and read everything here, and it asks before changing anything.
