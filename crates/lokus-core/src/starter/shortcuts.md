On Windows and Linux, use Ctrl where this says ⌘.

| Do this | Press |
| --- | --- |
| Go to a note | ⌘ O |
| Search in all notes | ⌘ ⇧ F |
| Every command | ⌘ ⇧ P |
| New note | ⌘ N |
| Today's note | ⌘ ⇧ D |
| Go to a heading | ⌘ ⇧ O |
| Assistant | ⌘ J |
| Graph | ⌘ G |
| Show or hide the sidebar | ⌘ \ |
| Settings | ⌘ , |
| Bold, italic, code | ⌘ B, ⌘ I, ⌘ E |
| Link | ⌘ K |

Everything else is in the command list (⌘ ⇧ P): templates, version history, the trash, plugins.
