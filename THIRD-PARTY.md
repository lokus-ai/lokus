# What Lokus includes that others made

Lokus is built on open-source work. The full list, with each licence, comes from the lock files:
`cargo tree` for the Rust side and `pnpm licenses list` for the interface. The parts that are
shipped inside the app as files, rather than compiled in, are these:

| What | Whose | Terms |
|---|---|---|
| Inter (the interface typeface) | The Inter Project Authors | SIL Open Font License 1.1 |
| JetBrains Mono (the code typeface) | JetBrains | SIL Open Font License 1.1 |
| Lucide icons | Lucide Contributors | ISC |
| Service marks from Simple Icons | Simple Icons Collaborators | CC0 1.0 for the collection |
| Tauri, ProseMirror, Yjs/yrs, React | their authors | MIT or Apache-2.0 |

## Names and logos

The names and logos of other products shown in Lokus (Slack, Linear, Notion, Granola, Stripe and
the rest) belong to their owners. They appear only to say which service a connection is for.
Lokus is not affiliated with, endorsed by or sponsored by any of them. An owner who wants a
mark removed or changed can open an issue and it will be.
