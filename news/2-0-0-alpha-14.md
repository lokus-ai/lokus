title: Team sync that stays on, and connections per workspace
summary: A team workspace now always syncs, and each workspace has its own Slack, GitHub and other connections. Edit a task's assignee, status, priority and due date on the board and add your own columns. A chat message you were writing is still there when you come back.
version: 2.0.0-alpha.14
show: quiet
---
**Team sync**

- **A team workspace always syncs.** There is no Stop button and nothing to press: open a team's folder and it connects. A workspace stopped earlier comes back by itself
- **Leave and Delete take the workspace off your list.** Your notes stay on your computer. If an owner deletes a workspace or removes you, Lokus says so once and stops trying
- A note with Windows line endings arrives with them on a teammate's computer
- When sync fails, Lokus reports why (never a note, a title or a name), so a problem can be found without asking you for a log

**Connections**

- **Each workspace has its own connections.** Slack, GitHub and the rest can be different in every workspace. What you had connected is in each workspace you already have, and a new workspace starts with none
- Moving or renaming a workspace folder keeps its connections

**Tasks**

- **A task shows whether an edit is saved.** Unsaved, saving, saved or failed; a failed edit keeps what you typed and offers Retry
- **Edit on the board.** Assignee, status, priority and due date change in place, without opening the task
- **Your own columns.** Add, rename and remove columns on a board. An empty column stays
- **Delete a task** from the board. It goes to the trash like any note

**Assistant**

- **A message you were writing is kept,** with its attachments, when you close the chat, open another conversation or switch folder
- A suggestion from Noticed that finishes late stays in the conversation and folder it was started in
- Connecting the same provider again keeps the model you chose

**Menus**

- **The Mac menu bar carries Lokus's commands,** including Settings, and each goes to the window in front
- Closing Settings puts the cursor and selection back where they were, including inside a table cell

**Fixed**

- With two windows open, a window can only change the folder it shows
- Renaming a file or folder while another folder is opening is refused instead of landing in the wrong place
- Your cursor and name are no longer sent to teammates in a different team folder during a switch
- An invitation approved in the browser while setup is asking about it is taken as joined, without another click
