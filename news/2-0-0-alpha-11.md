**Fixed**

- **A picture whose file name has brackets is drawn.** `![logo](attachments/logo-(png).png)` stayed as text; it now shows the picture, and so does a name with spaces written as `<my file.png>`
- **A web link inside a table reads as its words.** It showed `[words](address)` as written; it now opens the address on a click, and a click beside it edits the cell
- **A note a teammate deletes closes here too.** It stayed open and took typing that went nowhere; its tab now closes and says the note is in the trash
- **A shared note shows what teammates typed the moment you come back to its tab.** It showed the text from before until something else changed
- **A click on the tab you are already in no longer puts old text back,** which could then be saved over what you had typed
- **A note with a web link written over two lines opens,** and no longer writes its text into the other notes you have open
- A web link written with escaped brackets opens the address it names
- A note with a picture written over two lines opens again
