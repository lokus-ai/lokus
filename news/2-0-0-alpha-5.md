**Fixed**

- **New notes in a team workspace.** Naming a new note and then typing lost the text: it never reached the file or your teammates. It does now
- The sidebar says **Team** or **Private** beside the workspace name, so you can see what is shared

**New for teams**

- **What the assistant notices is shared.** One person's Lokus does the look, everyone sees the findings, and dealing with one clears it for all
- **One look, not five.** With several people in a workspace, only one assistant looks each time
- **One meeting is one record**, even when several people recorded it
