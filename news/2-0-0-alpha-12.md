**Fixed**

- **Paste a Claude or OpenAI key during setup.** The key option now opens a form where it is asked for, instead of trying to open Settings before a folder exists
- **Adding a customer column leaves the table where it was.** The list of existing details scrolls on its own, with the new-detail form below it
- **The Add column panel fits beside the assistant,** rather than opening underneath it or beyond the page
- **Typing with the graph, a picture or a PDF in front no longer changes the note behind it.** Return to the note and typing works without another click

**Team invitations**

- Invitations joined on the invitation page are picked up when you return to Lokus, without a second Join click in the app. During first-run setup, that team comes before setting up a personal folder
- This requires your team's relay to have the updated invitation page. Older invitation pages keep working with the existing in-app Join button
