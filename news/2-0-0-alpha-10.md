**New**

- **Tables are edited as tables.** Click a cell and type; Tab and Enter move on, and a right click adds or removes a row or a column. The note underneath is still plain Markdown
- **Lokus for Windows and Linux.** A Windows installer and a Linux AppImage now come with every release. Windows asks before running the installer: choose "More info", then "Run anyway"

**Fixed**

- A Slack message on a customer's page shows names, links and bold the way Slack does, not Slack's raw code
- A note changed outside Lokus no longer moves your place in it
